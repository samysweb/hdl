\title{Heterogeneous Dynamic Logic:\\Instantiation for Differential Dynamic Logic}
%\author{}
\maketitle

\begin{abstract}
Formally verifying systems that combine multiple programming
languages requires reasoning across distinct program logics at once.
\emph{Heterogeneous Dynamic Logic}~\cite{DBLP:journals/corr/abs-2507-08581} (HDL) enables this reasoning by framing individual
program logics as \emph{dynamic theories} which instantiate a general Isabelle locale.
This formalization proves that the AFP formalization of Differential Dynamic Logic~\cite{Differential_Dynamic_Logic-AFP} \emph{instantiates}
the dynamic theory locale of the HDL Isabelle formalization.
\end{abstract}
